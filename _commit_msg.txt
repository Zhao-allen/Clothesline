feat: add "Buy me a coffee" donation support

Adds a support-the-author entry to the tray menu that opens a glass-morphism
window showing a scannable QR code.

- UI/DonationWindow.cs: new borderless WPF window matching the installer's
  dark glass style - rounded translucent card, drop shadow, inner top-left
  glow, drag-to-move, close button. QR loads from the embedded pack URI with
  a file-next-to-exe fallback; if neither is present it shows the replacement
  hint text instead of an empty box.
- UI/TrayIcon.cs: new row between "Check for updates" and "Quit", using a
  hand-authored coffee-cup icon (IcoCoffee) alongside the other stroked glyphs.
- Resources/donation_qr.png: placeholder QR pointing at the project repo.
  Replace this file with your own payment code - it is copied to the output
  directory as well as embedded, so it stays user-editable.
- i18n: BuyMeACoffee / DonationTitle / DonationBody / DonationReplaceHint
  added to all five string tables (en, zh, es, ja, fr) and to the designer.
- Clothesline.csproj: the image is both <Resource> (embedded, pack URI) and
  <Content> (copied to Resources\ next to the exe) so both load paths work.

Note: this project sets UseWPF and UseWindowsForms, so several types collide.
DonationWindow.cs aliases the WPF ones explicitly (Image, MouseEventArgs,
HorizontalAlignment etc.), matching the convention already used in TrayIcon.cs.
